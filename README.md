# WarsawES
This repository contains code snippets for analysis conducted during the preparation of the manuscript "The socio-cultural values of ecosystem services in managed, semi-managed and low-managed urban blue spaces and their surroundings. A case study of Warsaw, Poland", accepted in Cities.
  Preprocessing.R script contains the code used to prepare original data for analysis. Unfortunately, original data cannot be made available publicly as they contain personal data.
  Ridges_plots.R script contains the code used to produce Figure 3.
  PCA and K-means clustering.R script contains the code used to produce Figure 5 and Figures S1 and S2.
  Heatmaps.R script contains the code used to produce Figures 7 and 9.
